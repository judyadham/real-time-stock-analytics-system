# Real-Time Stock Analytics & Prediction System

## Overview
This project presents an end-to-end stock analytics system designed for market analysis and investment support using historical and real-time stock data.

## Features
- Historical and real-time stock data acquisition
- Data preprocessing and feature engineering
- Exploratory Data Analysis (EDA)
- Predictive modeling and stock trend analysis
- Real-time alerts
- Portfolio recommendation
- Interactive dashboard

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
- yfinance
- Matplotlib
- Streamlit

## Dataset
Feature-engineered datasets from multiple banking stocks were uploaded and used specifically for predictive modeling and analysis.
Real-time alerts and monitoring functionality rely on dynamically collected market data through yfinance integrated with machine learning components.

## Project Structure
The project is divided into multiple notebooks representing each phase of the workflow.
